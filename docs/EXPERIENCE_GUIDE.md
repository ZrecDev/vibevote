# Experience Lead Guide

Own `apps/web/app`, `components`, `features`, `styles`, `packages/ui`, Sites prototypes, UX, accessibility, PWA surfaces, frontend tests, and user-facing product documentation. Work against merged contracts and mocks; never recreate authorization, score, RNG, or finalization logic in the client.

Use Sites for mobile UX exploration, clickable prototypes, user testing, visual direction, and landing-page experiments. Build the complete conceptual path there first: landing, setup, constraints, options, lobby, private voting, completion, result, and sharing. Validate it with real groups, then translate approved designs into production components.

Accessibility: visible alternatives to swipe, keyboard-order and focus checks, named controls, comfortable touch targets, non-color vote distinction, reduced-motion support, announced loading/live changes, preserved valid form input, and light/dark contrast.
